Kto korzysta

Aplikacja jest prywatnym narzędziem jednego użytkownika (autora) i działa wyłącznie na jego komputerze.

Jakie dane

Za zgodą użytkownika aplikacja odczytuje z jego konta Google, tylko do odczytu: kontakty (Google Contacts, przez CardDAV) oraz listę plików i folderów na Dysku Google.

Co się z nimi dzieje

  • Dane są zapisywane wyłącznie lokalnie, w prywatnych notatkach użytkownika na jego komputerze i telefonie.
  • Aplikacja niczego nie zmienia ani nie usuwa na koncie Google.
  • Dane nie są sprzedawane, udostępniane ani przekazywane osobom trzecim i nie służą do reklam.
  • Dostęp można w każdej chwili odebrać na stronie myaccount.google.com/permissions.

Sposób wykorzystania danych z interfejsów Google jest zgodny z Google API Services User Data Policy, w tym z wymaganiami „Limited Use”.

English: This is a private, single-user tool. With the user's consent it reads, in read-only mode, the user's Google Contacts and Google Drive file list. Data is stored only locally on the user's own devices, is never modified on Google, and is never sold, shared or transferred to third parties. Use of Google API data adheres to the Google API Services User Data Policy, including the Limited Use requirements.
